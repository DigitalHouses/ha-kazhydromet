# Kazhydromet for Home Assistant

Нативная интеграция Home Assistant для наблюдений Казгидромета (WIS2).

> Статус: разработка. Установка через HACS будет доступна после проверки источников и первого выпуска.

Репозиторий поддерживается DigitalHouses. Архитектура: `WeatherEntity`, `ConfigFlow`, прямое подключение к API без MQTT и отдельного приложения.

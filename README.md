# Казгидромет для Home Assistant

Нативная интеграция Home Assistant для **фактических метеонаблюдений Казгидромета**. Без приложения Supervisor, MQTT и отдельных контейнеров.

**Статус: предварительная версия 0.1.0, требует испытания на реальном HA.** Источник: официальный WIS2 OGC API Features.

## Возможности первой версии

- Одна нативная сущность weather с температурой, облачностью, ветром, давлением и видимостью (при наличии данных в отчёте SYNOP).
- Автоматический выбор ближайшей станции с актуальным температурным измерением (по координатам HA) или ручной выбор WIGOS-станции.
- Диагностические сенсоры: выбранная станция и реальное время наблюдения.
- Обновление каждые 30 минут, строгая проверка временных меток (максимальный возраст наблюдения — 4 часа).
- Отсутствующие измерения не заменяются выдуманными нулями. Недоступные/устаревшие данные отображаются как unavailable.

**Важно:** суточный и почасовой прогноз **пока не включён**. Официальный каталог WRF JSON найден, но его большой документ и формат ещё не удалось достоверно проверить. До проверки схемы интеграция не будет подставлять прогноз другого сервиса и выдавать его за Казгидромет.

## Установка через HACS

1. HACS → меню ⋮ → Custom repositories.
2. Добавить https://github.com/DigitalHouses/ha-kazhydromet как Integration.
3. Установить Kazhydromet и перезапустить Home Assistant.
4. Настройки → Устройства и службы → Добавить интеграцию → Kazhydromet.
5. Выбрать автоматический поиск станции или конкретную метеостанцию.

Пока релиз не проверен на живых наблюдениях, используйте только для тестов и не привязывайте к критическим автоматизациям.

## Источники и ограничения

- Наблюдения: https://wis2box.kazhydromet.kz/oapi (коллекция SYNOP).
- Прогноз для следующего этапа: https://www.kazhydromet.kz/vc/wrf/ftp2/api/forecast_latest.json.
- Фактические измерения принадлежат станции, а не точным координатам дома. Ближайшая станция может находиться на иной высоте.
- Из-за ограничений API или задержки публикации доступность измерений конкретной станции не гарантируется.
- Необходимо отдельно проверить условия коммерческого использования данных Казгидромета.
